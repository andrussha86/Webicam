# Webicam 0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пресеты (встроенные и свои), замена фона картинкой или цветом, фокус по лицу и статус реакций iOS — от протокола до интерфейса на обеих сторонах.

**Architecture:** Протокол v3 расширяет `CameraSettings`/`CameraState` и добавляет `BackgroundImage`. ПК решает всё, что связано с файлами (пресеты, картинки, рендер встроенных фонов, JPEG через WIC) в `webicam_core`, приложение только рисует. iPhone компонует кадр по маске Vision с картинкой или цветом и выставляет системные флаги лица.

**Tech Stack:** C++23, MSVC, GoogleTest, WIC, Dear ImGui (D3D11); Swift 5.9, SwiftUI, AVFoundation, Vision, Core Image, XCTest; GitHub Actions CI.

**Spec:** `docs/superpowers/specs/2026-10-27-webicam-0.3-presets-backgrounds-design.md`

## Global Constraints

- Протокол: `kProtocolVersion = 3` (ПК) и `ProtocolConstants.version = 3` (iOS), совместимости с v2 нет.
- iOS: `CFBundleShortVersionString "0.3.0"`, `CFBundleVersion "4"`, deployment target 17.0 без изменений.
- Пути ПК: `%LOCALAPPDATA%\Webicam\settings.ini`, `presets.ini`, `backgrounds\`.
- Видимые строки интерфейса (обе стороны): ноль символов `—` и `–`, без эмодзи, кнопки в одну строку при ширине панели 360 px.
- Палитра только из `theme.h` / `Theme.swift`: акцент `kAccent` значит «включено/выбрано», `kDanger` значит ошибка. Новых цветов интерфейса нет (цвета фонов и образцов — это контент, не интерфейс).
- Скругления: все новые элементы используют `ImGui::GetStyle().FrameRounding` (поля, плитки, образцы); никаких кругов и «таблеток».
- Движение: только существующие переходы; новые анимации не добавляются.
- Записи файлов атомарные: temp + `MoveFileExW(MOVEFILE_REPLACE_EXISTING)`, как `SaveSettings`.

## Review Focus

1. Пресет с форматом, которого нет у телефона, применяется во время трансляции → тот же размер с fps = min(нужный, max телефона) или формат не меняется с подсказкой. Тест: Task 3 `Presets_MatchFormat*`.
2. Переподключение при `background_mode = 2` → телефон получает `BackgroundImage` раньше `CameraSettings`, иначе первые кадры без фона или с ошибкой. Тест: Task 6 `ConnectionManager_SendsBackgroundBeforeSettings`.
3. Огромная своя картинка (например 12000×8000 PNG) → загружается, масштабируется до кадра, JPEG 4K < 16 МиБ. Тест: Task 5 `ImageCodec_Jpeg4kFitsFrameLimit`.
4. Удаление своей картинки, на которую ссылается пресет → отказ с именем пресета. Тест: Task 5 `BackgroundLibrary_RemoveRefusesReferenced`.
5. Имя пресета «стрим» при встроенном «Стрим», кириллица в другом регистре → отказ. Тест: Task 3 `Presets_NameCaseInsensitiveCyrillic`.
