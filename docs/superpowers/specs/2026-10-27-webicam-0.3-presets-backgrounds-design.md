# Webicam 0.3 — пресеты, замена фона, фокус по лицу, реакции

Дата: 2026-10-27
Статус: объём и схема утверждены в чате; ждёт ревью спецификации

## Цель

1. **Пресеты.** Одним кликом переключать готовые наборы: настройки камеры + фон + формат видео
   (разрешение, fps, битрейт). Есть встроенные («Созвон», «Стрим», «Тёмная комната») и свои.
2. **Замена фона.** Кроме размытия — подложить картинку (встроенную или свою с ПК) или
   однотонный цвет за человеком.
3. **Фокус по лицу.** Переключатель «Следить за лицом»: фокус и экспозиция держатся на лице.
4. **Реакции iOS.** Системные эффекты iOS 17 (сердечки, конфетти, фейерверк…) запускаются
   жестами рук. ПК показывает, включены ли они и где их включить. Кнопок запуска на ПК нет.

Логотип и иконки — отдельная задача, не входит в эту спецификацию.

До 1.0 совместимость не поддерживается: протокол становится версии 3.

## Протокол v3

| Type | Code | Direction | Payload |
|---|---|---|---|
| CameraSettings | 0x08 | PC → phone | поля v2 без изменений, затем `face_focus: bool, background_mode: u8, background_color: u32` |
| CameraState | 0x09 | phone → PC | поля v2 без изменений, затем `reactions_supported: bool, reactions_enabled: bool, gestures_enabled: bool` |
| BackgroundImage | 0x0A | PC → phone | JPEG до конца payload (может быть пустым — «картинки нет») |

- `background_mode`: 0 выключен, 1 размытие (сила — существующее поле `blur`, 1…100;
  `blur = 0` при режиме 1 трактуется как 1), 2 картинка, 3 цвет. Значение ≥ 4 — ошибка протокола.
- `background_color`: `0x00RRGGBB`, старший байт должен быть 0, иначе ошибка протокола.
- `BackgroundImage` — последняя присланная картинка, телефон держит её до конца соединения.
  ПК шлёт её при выборе новой картинки и после каждого `Configure` (до `CameraSettings`),
  если `background_mode = 2`. Порядок гарантирует TCP, поэтому идентификатор не нужен.
  ПК масштабирует картинку «с обрезкой по краям» (cover) ровно до разрешения потока и
  кодирует JPEG качества 85; при 4K это ≈ 1–2 МБ, в лимит 16 МиБ укладывается с запасом.
- Режим 2 без картинки или с битым JPEG: телефон отдаёт кадр без обработки и шлёт
  `Status{error, "Не удалось открыть картинку фона"}` один раз на картинку.
- `reactions_supported` — `activeFormat.reactionEffectsSupported`;
  `reactions_enabled` — `AVCaptureDevice.reactionEffectsEnabled`;
  `gestures_enabled` — `AVCaptureDevice.reactionEffectGesturesEnabled`.

Новые тест-векторы: `camera_settings.bin` и `camera_state.bin` пересобираются под v3,
добавляются `background_image.bin` (3 байта `FF D8 FF`) и `background_image_empty.bin`.
`hello_*.bin` получают версию 3.

## iPhone

### Фон (`BackgroundBlur` → `BackgroundCompositor`)

Класс переименовывается: он теперь не только размывает. Маска — как в 0.2
(`VNGeneratePersonSegmentationRequest .balanced`, не чаще 30 раз/с). Меняется только подложка
для `blendWithMask`:

| Режим | Подложка |
|---|---|
| 1 размытие | как в 0.2 |
| 2 картинка | `CIImage(data:)` из `BackgroundImage`, масштаб «cover» под размер кадра; результат кэшируется до смены картинки или размера кадра |
| 3 цвет | `CIImage(color:)`, обрезанная по кадру |

Режим 0 — кадр идёт мимо, как `blur = 0` в 0.2. Смена режима сбрасывает маску (`reset()`).
Поворот на 180° делает сама сессия захвата (угол соединения) ещё до компоновки, поэтому
картинка фона в кадре всегда стоит прямо.

### Фокус по лицу

При `face_focus = true` и авто-фокусе:
`automaticallyAdjustsFaceDrivenAutoFocusEnabled = false`, `isFaceDrivenAutoFocusEnabled = true`;
то же для экспозиции, если экспозиция в авто. При `false` — оба флага `isFaceDriven…Enabled = false`
(тоже с отключённым `automaticallyAdjusts…`), чтобы поведение было предсказуемым.
При ручном фокусе/экспозиции флаг для соответствующего параметра не трогается.

Риск: если на реальном устройстве системные флаги не дают заметного эффекта с задней камерой,
запасной путь — `AVCaptureMetadataOutput` с типом `.face` и установка
`focusPointOfInterest`/`exposurePointOfInterest` в центр самого большого лица не чаще 4 раз/с.
Решение принимается после ручной проверки (см. чек-лист); протокол от этого не меняется.

### Реакции

- `Info.plist`: `NSCameraReactionEffectGesturesEnabledDefault = true`, чтобы жесты работали
  сразу после включения реакций.
- `CameraState` несёт три флага выше. Включить реакции приложение не может — это делает
  пользователь в Пункте управления → «Видеоэффекты», пока Webicam открыта.
- Эффекты рисует система прямо в кадр камеры, до нашей обработки. Поэтому при включённой
  замене фона или размытии эффекты видны только поверх человека — это известное
  ограничение, о нём пишет подсказка на ПК.

## ПК

### Встроенные фоны (`core/backgrounds`)

8 фонов генерируются кодом, без файлов-картинок: функция
`RenderBuiltinBackground(index, width, height) → BGRA`. Мягкие градиенты в палитре приложения
(«Графит», «Сумерки», «Тёплая студия» с пятном света, «Холодная студия», «Туман» — светлый
нейтральный, «Мох», «Песок», «Ночь»), плюс лёгкое зерно (±1.5 уровня), чтобы H.264 не рисовал
полосы на градиенте. Зерно детерминированное (фиксированный seed), чтобы рендер был тестируемым.

### Картинки и кодирование (`core/image_codec`)

- Через WIC: загрузка любого поддерживаемого Windows формата (JPEG, PNG, BMP, GIF, TIFF, HEIC
  при наличии расширения), cover-масштаб `WICBitmapInterpolationModeFant`, JPEG q=85.
- Свои картинки при добавлении копируются в `%LOCALAPPDATA%\Webicam\backgrounds\`
  под именем `<FNV-1a 64 всего файла, 16 hex>.<ext в нижнем регистре>`, дубликаты не плодятся.
- Миниатюры 160×90 для интерфейса создаются тем же кодом и живут как D3D-текстуры, пока
  открыто окно.

### Ссылка на фон

Фон в настройках и пресетах — строка `background_image`: `builtin:<0…7>` или имя файла
в папке `backgrounds`. Если файла нет — режим «картинка» не применяется, в UI подсказка
«Картинка не найдена», остальное из пресета применяется.

### Пресеты (`core/presets`)

Пресет = имя + `CameraSettings` + `background_image` + `width/height/fps/bitrate_kbps`.

Встроенные (в коде, не удаляются и не перезаписываются):

| Имя | Формат | Битрейт | Камера и фон |
|---|---|---|---|
| Созвон | 1280×720, 30 к/с | 4 Мбит/с | основной объектив, всё авто, лицо вкл., размытие 60 |
| Стрим | 1920×1080, 60 к/с | 20 Мбит/с | основной объектив, всё авто, лицо вкл., фон выкл. |
| Тёмная комната | 1920×1080, 30 к/с | 10 Мбит/с | основной объектив, авто, экспокоррекция +1.0 EV, лицо вкл., фон выкл. |

Свои пресеты — `%LOCALAPPDATA%\Webicam\presets.ini`:

```
[Мой стол]
width=1920
height=1080
fps=30
bitrate_kbps=12000
background_image=builtin:2
lens=1
...остальные ключи CameraSettings, как в settings.ini
```

- Имя: 1–32 символа, без `[`, `]` и переводов строки, уникально без учёта регистра, не
  совпадает со встроенными. Сохранение под существующим своим именем перезаписывает его
  после подтверждения.
- Запись атомарная (temp + `MoveFileEx`), как у `settings.ini`. Битая секция пропускается,
  остальные загружаются.
- Применение: камера и фон — сразу; формат — если телефон умеет ровно такой
  `width×height@fps`. Иначе берётся тот же размер с наибольшим доступным fps ≤ нужного,
  а если и размера нет — формат не меняется и показывается подсказка
  «Формат 1920×1080, 60 к/с недоступен на этом iPhone».
- Активный пресет запоминается в `settings.ini` (`preset=<имя>`). Если текущие настройки
  отличаются от него, рядом с именем пишется «изменён».

`settings.ini` получает ключи `face_focus`, `background_mode`, `background_color`,
`background_image`, `preset`. Старый файл без них читается: при `blur > 0` режим = размытие.

### Интерфейс

- Новая секция **«Пресет»** самой первой: выпадающий список (сначала встроенные, затем
  свои через разделитель), справа кнопки «Сохранить» (окошко с полем имени) и «Удалить»
  (только для своих, с подтверждением).
- Секция **«Фокус»**: переключатель «Следить за лицом» под авто/ручным; при ручном фокусе
  он неактивен с подсказкой «Работает в авто-режиме».
- Секция **«Фон»**: сегменты «Выкл. · Размытие · Картинка · Цвет».
  - Размытие — существующий ползунок.
  - Картинка — сетка миниатюр 4 в ряд: 8 встроенных, затем свои, последней плитка «+»
    (системный диалог выбора файла). У своих при наведении крестик «Убрать» — удаляет
    файл из `backgrounds`, если на него не ссылается ни один пресет; иначе подсказка
    «Используется в пресете „…“».
  - Цвет — 6 образцов + `ColorEdit3` без альфы.
  - При реакциях, включённых на телефоне, и любом режиме кроме «Выкл.» — подсказка
    «Реакции видны только поверх вас».
- Строка **«Реакции»** в конце секции «Фон» (только при подключённом телефоне):
  «Включены: покажите руками большой палец, „викторию“ или сердечко» / «Выключены: на iPhone
  откройте Пункт управления → Видеоэффекты → Реакции» / «Недоступны в этом формате».
  Без эмодзи: в Geist их нет.

## Ошибки

| Ситуация | Поведение |
|---|---|
| Файл картинки не читается WIC | Строка ошибки под сеткой фонов «Не удалось открыть картинку: <путь>», в список не добавляется |
| Картинка из пресета удалена | Остальное из пресета применяется, фон «выкл.», подсказка «Картинка не найдена» |
| Телефон не смог декодировать JPEG | `Status{error}` → строка ошибки в окне, кадры идут без обработки |
| Формат пресета недоступен | Правило подбора выше + подсказка |
| `presets.ini` не записался | Подсказка «Не удалось сохранить пресет», пресет остаётся в памяти до выхода |

## Тесты

Автоматические (обе стороны, где применимо):
- протокол: новые/обновлённые векторы, отказ на `background_mode = 4` и на цвет с ненулевым
  старшим байтом;
- `presets`: round-trip, битая секция пропускается, валидация имён, встроенные нельзя
  удалить/перезаписать, подбор формата (точный / тот же размер с меньшим fps / недоступен);
- `settings_store`: старый файл без новых ключей → режим из `blur`;
- `backgrounds`: детерминированность (хэш рендера 64×36 для каждого индекса), размер выхода;
- `image_codec`: cover-масштаб (пропорции и размер результата), JPEG начинается с `FF D8`;
- iOS: `MessageParser` для `BackgroundImage` и новых полей.

Вручную (`docs/manual-test-checklist.md`, раздел «0.3»): каждый режим фона, своя картинка
PNG и HEIC, переключение пресетов во время трансляции в OBS, «Следить за лицом» на основном
объективе (лицо в стороне от центра остаётся резким), реакции жестами с фоном и без.
