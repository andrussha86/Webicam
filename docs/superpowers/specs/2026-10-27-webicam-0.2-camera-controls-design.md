# Webicam 0.2 — управление камерой, размытие фона, гашение экрана

Дата: 2026-10-27
Статус: утверждено в чате («всё сразу в 0.2», «быстро и дёшево»)

## Цель

Из окна `webicam.exe` во время трансляции менять: объектив (0.5× / 1× / 2× / 3× / фронтальная),
зум, ISO, выдержку, экспокоррекцию, цветовую температуру и оттенок, фокус, силу размытия фона,
поворот на 180°. Настройки запоминаются на ПК и отправляются на iPhone при каждом подключении.
Экран iPhone во время работы гаснет (чёрный экран + минимальная яркость), касание будит.

До 1.0 совместимость между версиями не поддерживается: протокол становится версии 2,
при несовпадении `Hello` закрывает соединение и UI просит обновить приложение.

## Протокол v2

Новый тип `f32` — IEEE 754 single, little-endian.

| Type | Code | Direction | Payload |
|---|---|---|---|
| CameraSettings | 0x08 | PC → phone | `lens: u8, zoom: f32, manual_exposure: u8, iso: f32, shutter_us: u32, exposure_bias: f32, manual_wb: u8, temperature_k: f32, tint: f32, manual_focus: u8, lens_position: f32, blur: u8, rotate180: u8` |
| CameraState | 0x09 | phone → PC | `lenses: u8` (bit i — объектив i есть), `lens: u8`, `iso_min: f32, iso_max: f32, shutter_min_us: u32, shutter_max_us: u32, bias_min: f32, bias_max: f32, zoom_max: f32, manual_focus_supported: u8`, `iso: f32, shutter_us: u32, temperature_k: f32, tint: f32, lens_position: f32` |

Объективы: 0 — сверхширокий (0.5×), 1 — основной (1×), 2 — основной с зумом 2×, 3 — телевик,
4 — фронтальный. `zoom` ≥ 1 — множитель внутри объектива. `blur` 0–100, 0 — выключено.

- `CameraSettings` — полный снимок, идемпотентен. ПК шлёт его после `Configure` при каждом
  подключении и при изменениях (не чаще 20 раз/с). Телефон зажимает значения в допустимые
  диапазоны текущего объектива.
- `CameraState` телефон шлёт после смены объектива/формата и раз в 0.5 с: диапазоны
  для ползунков и текущие автоматические значения (видны, пока параметр в «авто»).
- После каждого `Configure` телефон шлёт `Status` с фактическим состоянием (стрим/пауза),
  чтобы ПК не показывал устаревшую «остановлено» (баг 0.1).

## iPhone

- `CaptureEngine` хранит формат и `CameraSettings`. Смена объектива = замена входа сессии
  (картинка замирает ~0.5 с) и повторное применение формата; если объектив не умеет запрошенный
  FPS, берётся максимальный FPS этого объектива при том же разрешении; если не умеет
  разрешение — `Status{error}` и объектив не меняется. Выдержка ограничена сверху `1/fps`.
- Ручные режимы: `setExposureModeCustom`, `setWhiteBalanceModeLocked` (температура/оттенок →
  gains, зажатые в `1…maxWhiteBalanceGain`), `setFocusModeLocked(lensPosition:)`; авто —
  `continuousAuto*` и `setExposureTargetBias`.
- Размытие (`BackgroundBlur`): `VNGeneratePersonSegmentationRequest` (.balanced), маска
  пересчитывается не чаще 30 раз/с, Core Image: размытый фон + `blendWithMask` → NV12-буфер
  из пула → кодер. При `blur = 0` кадр идёт мимо.
- Экран: через 10 с без касаний — чёрный экран без интерфейса, яркость 0; касание
  возвращает интерфейс и исходную яркость пользователя; при уходе из приложения яркость
  восстанавливается.

## ПК

- `ConnectionManager`: `SetDesiredCamera`, отправка после `Configure`; колбэк `onCameraState`.
- `settings_store`: `%LOCALAPPDATA%\Webicam\settings.ini` (key=value) — формат, битрейт,
  `CameraSettings`. Сохраняется через секунду после последнего изменения и при выходе.
- UI: секции «Объектив», «Экспозиция», «Баланс белого», «Фокус», «Фон», кнопка «Всё в авто».
  У параметра в «авто» ползунок неактивен и показывает текущее значение с телефона.
- Пока идут кадры, статус «остановлено на iPhone» сбрасывается.

## Тесты

Новые векторы `camera_settings.bin`, `camera_state.bin` (обе стороны), round-trip настроек
в `settings_store`. Камера, Vision и экран проверяются вручную (`docs/manual-test-checklist.md`).
