# Ручная проверка (подпроект 1)

Отмечайте результат и дату. Устройство: iPhone 15 Pro, Windows 11.

## Без телефона

- [ ] `install.ps1` от администратора → «виртуальная камера зарегистрирована».
- [ ] `vcam-probe` + приложение «Камера» → камера «Webicam» показывает движущиеся цветные полосы.
- [ ] `vcam-check --width 1280 --height 720` (при запущенном `vcam-probe`) → кадры 1280×720,
      `Y[0]` меняется от кадра к кадру (полосы), а не стоит на 32 (заглушка).
- [ ] `vcam-probe --stop-heartbeat-after 5` → через ~6 с затемнённый кадр с «Нет сигнала».
- [ ] `fake-phone` + `webicam.exe --direct 127.0.0.1:47800` → в OBS 1080p мигающая по яркости
      картинка, в окне задержка < 30 мс; убить `fake-phone` → «Нет сигнала» ≤ 2 с; снова
      запустить → картинка возвращается сама.

## С iPhone

- [ ] Первое подключение: запрос «Доверять», затем «Подключено: iPhone16,1».
- [ ] В OBS живое видео 1080p60; через 30 минут работы — стабильно, без нарастания задержки.
- [ ] Выдернуть кабель → «Нет сигнала»; вставить → картинка возвращается без перевыбора камеры.
- [ ] Заблокировать iPhone / свернуть приложение → «Нет сигнала»; вернуться → видео.
- [ ] Смена разрешения в `webicam.exe` (720p30 → 4K30 → 1080p60) без перезапуска потребителя.
- [ ] Два потребителя одновременно (OBS + браузер).
- [ ] Камера видна в: приложении «Камера», Zoom, Chrome/Edge, OBS.
- [ ] «Пауза» на iPhone → «Трансляция остановлена на iPhone» в окне ПК и «Нет сигнала» в OBS.
- [ ] Запуск второго `webicam.exe` → сообщение «Webicam уже запущен».

## 0.2: управление камерой

- [ ] Объективы 0.5× / 1× / 2× / 3× / фронтальная переключаются, картинка замирает не дольше ~0.5 с.
- [ ] Зум в пределах объектива плавный; при переключении объектива зум сбрасывается в 1.
- [ ] Экспозиция «Авто» снята → ползунки ISO и выдержки меняют картинку; «Сейчас: ISO …» в авто
      совпадает с тем, что видно.
- [ ] Выдержку нельзя сделать длиннее 1/FPS (FPS в статистике не падает).
- [ ] Баланс белого: 2500 K синит, 10000 K желтит; оттенок сдвигает в зелёный/пурпурный.
- [ ] Ручной фокус: 0 — резко вблизи, 1 — вдали; на фронтальной камере ручной фокус недоступен.
- [ ] Размытие фона 0 → 100: фон размывается, человек резкий; 1080p60 держит ≥ 55 кадров/с.
- [ ] «Повернуть на 180°» переворачивает картинку (фронтальная камера/перевёрнутый держатель).
- [ ] «Всё в авто» возвращает авто-режимы, объектив и поворот не трогает.
- [ ] Закрыть и снова открыть `webicam.exe` → все настройки на месте и применяются к iPhone.
- [ ] Старое приложение 0.1 на iPhone → в окне «обновите приложение на iPhone».
- [ ] Через 10 с без касаний экран iPhone чёрный, видео идёт; касание возвращает интерфейс и яркость;
      выход из приложения возвращает исходную яркость.
- [ ] «Пауза» на iPhone, затем «Возобновить» → надпись «Трансляция остановлена» на ПК исчезает.

## Задержка (объектив → экран)

## 0.3: пресеты, фон, лицо, реакции

- [ ] Подключение по кабелю: iPhone 0.2.1+ уходит из «Ожидание компьютера», картинка идёт.
- [ ] «Фон → Размытие»: ползунок «Сила» меняет размытие на лету.
- [ ] «Фон → Картинка»: каждый из 8 встроенных фонов виден за человеком, волосы и края без «ореола».
- [ ] «+» → своя PNG и своя HEIC: появляются в сетке, выбираются, видны на iPhone; повторное добавление той же картинки не плодит копию.
- [ ] Крестик на своей картинке: удаляется; если картинка в пресете, строка «Используется в пресете „…“».
- [ ] «Фон → Цвет»: каждый из 6 образцов и «Свой цвет».
- [ ] Режим «Картинка», выдернуть и вставить кабель: фон возвращается сразу, без «Не удалось открыть картинку фона».
- [ ] Смена разрешения при режиме «Картинка»: фон без растяжения.
- [ ] «Сохранить как» → «Мой стол» → появился в списке после встроенных; перезапуск webicam.exe, пресет на месте.
- [ ] Имя «стрим» → «Так называется встроенный пресет»; существующее имя → подсказка, второе нажатие заменяет.
- [ ] «Удалить» своего пресета с подтверждением; у встроенных кнопка неактивна.
- [ ] Переключение «Созвон» / «Стрим» / «Тёмная комната» во время трансляции в OBS: формат и фон меняются, OBS не теряет камеру.
- [ ] Пресет с 1080p60 на iPhone без 60 к/с в 1080p: берётся 30 к/с.
- [ ] Изменить зум после выбора пресета: рядом с «Пресет» появляется «изменён».
- [ ] «Следить за лицом» на основном объективе: лицо в стороне от центра остаётся резким и нормально экспонированным; при ручном фокусе переключатель неактивен.
- [ ] Реакции: строка «Реакции» показывает состояние; включить в Пункте управления → «Видеоэффекты» → «Реакции», показать большой палец и сердечко руками, эффект виден в OBS; с фоном эффект виден только поверх человека.

## 0.4: форматы, ориентация, отражение, область зума

- [ ] «+» в «Фон → Картинка»: окно выбора файла открыто, а webicam.exe продолжает рисовать превью; после выбора большой фотографии (48 Мп, HEIC) картинка появляется без подвисания.
- [ ] Боковая панель: вкладки «Кадр», «Камера», «Фон»; формат, частота и битрейт применяются сразу, кнопки «Применить» нет.
- [ ] «Кадр → 9:16»: на iPhone портретная картинка 1080×1920; в OBS при выборе 1080×1920 кадр без полос; при 1920×1080 — по бокам полосы и подсказка в webicam.exe.
- [ ] «Кадр → 4:3»: полный кадр сенсора 1920×1440 (или 1440×1080), картинка шире по вертикали, чем 16:9.
- [ ] Ориентация «Авто»: перевернуть телефон на 180° (в штативе вверх ногами) — картинка сама переворачивается за полсекунды; положить телефон экраном вверх — ничего не меняется. Работает и с блокировкой поворота.
- [ ] «Как есть» / «180°» отключают автоповорот.
- [ ] «Отразить по горизонтали» и «по вертикали» по отдельности и вместе, на основном и фронтальном объективах.
- [ ] Зум 2×: перетаскивание превью двигает область, мини-карта в углу показывает, где она; колесо мыши приближает к точке под курсором; двойной щелчок и «Вернуть в центр» центрируют.
- [ ] Зум с фоном «Размытие»: маска человека совпадает с ним при перетаскивании области.
