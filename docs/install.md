# Установка Webicam

Webicam превращает iPhone (iOS 17+), подключённый кабелем, в веб-камеру для Windows 11.
Всё ставится вручную, без App Store. Скачайте из [Releases](../../releases) последней версии
`Webicam-windows-x64.zip` и `Webicam.ipa`.

## 1. Компьютер (Windows 11)

1. Установите **«Apple Devices»** из Microsoft Store (или iTunes) — это служба, через которую
   Windows общается с iPhone по USB.
2. Распакуйте `Webicam-windows-x64.zip` в любую папку.
3. Дважды щёлкните `install.cmd` и подтвердите запрос администратора. Если окно не появилось,
   откройте PowerShell **от имени администратора** в этой папке и выполните
   `powershell -ExecutionPolicy Bypass -File .\install.ps1`.
   Скрипт копирует `webicam_vcam.dll` в `C:\Program Files\Webicam` и регистрирует камеру.
   Это нужно один раз (и после обновления DLL). Удаление — `uninstall.cmd`.
4. Запустите `webicam.exe`. Камера «Webicam» видна в системе, пока программа запущена
   (закрытие окна сворачивает её в трей; «Выход» — в меню значка в трее).

## 2. iPhone

1. Установите [Sideloadly](https://sideloadly.io/) на компьютер.
2. Подключите iPhone кабелем, перетащите `Webicam.ipa` в Sideloadly, войдите своим Apple ID
   и нажмите Start.
3. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика** — включить
   (телефон перезагрузится). Затем **Настройки → Основные → VPN и управление устройством** —
   доверять своему Apple ID.
4. При первом подключении к компьютеру разблокируйте iPhone и нажмите **«Доверять»**.

С бесплатным Apple ID подпись действует **7 дней**: потом приложение перестанет запускаться,
и его нужно переустановить через Sideloadly (он умеет делать это автоматически).

## 3. Работа

1. Откройте Webicam на iPhone (приложение должно оставаться на экране — в фоне iOS выключает камеру).
2. `webicam.exe` подключится сам и покажет «Подключено: iPhone…».
3. В Zoom / OBS / Teams / браузере выберите камеру **Webicam**.

Разрешение захвата меняется в окне `webicam.exe`; выходное разрешение выбирает программа,
которая использует камеру, — картинка масштабируется под него.
